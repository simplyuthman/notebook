# Neue Haas Grotesk Font Files

Drop your licensed font files here. The project expects the following files:

| File | Weight | Style |
|---|---|---|
| `NHaasGroteskDPW-45Lt.woff2` | 300 (Light) | normal |
| `NHaasGroteskDPW-55Rg.woff2` | 400 (Regular) | normal |
| `NHaasGroteskDPW-65Md.woff2` | 500 (Medium) | normal |
| `NHaasGroteskDPW-75Bd.woff2` | 700 (Bold) | normal |

Common file names vary by foundry/license source. If yours differ, update
`src/app/fonts.ts` to match.

Obtain a web license at:
https://www.myfonts.com/fonts/linotype/neue-haas-grotesk/
